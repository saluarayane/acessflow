# AccessFlow 🚌📱

**O celular é o passe.** Uma plataforma mobile-first de mobilidade urbana, com app para o usuário final e painel web de gestão para instituições. O AccessFlow é uma alternativa digital aos cartões físicos de transporte: o smartphone vira a credencial de embarque, com validação por NFC ou QR Code dinâmico, inclusive offline.
